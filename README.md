# Portafolio

Este proyecto consiste en el desarrollo de un portafolio web personal para un desarrollador full-stack junior, diseñado para presentar su perfil, habilidades y proyectos destacados.

El objetivo principal del proyecto es crear una página que funcione como carta de presentación.
La página incluye una sección de presentación con información personal, descripción profesional, fotografía y enlaces para descarga de CV y al perfil de github; una sección de habilidades técnicas y una sección de proyectos destacados. Por último incluye los datos de contacto.

El sitio fué desarrollado en HTML con estilos en CSS, aplicando Flexbox, grid y reglas @ para declaración de fuentes e importación de estilos. El diseño es responsivo para mejor visualización en diferentes resoluciones.
