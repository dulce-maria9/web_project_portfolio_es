# Portafolio

Este proyecto consiste en el desarrollo de un portafolio webpersonal para un desarrollador full-stack junnior, diseñado para presentar su perfil, habilidades y proyectos destacados.
El objetivo principal del proyecto es crear una página que funciones como carta de presentación.
La página incluye una sección de presentación con información personal, descripción profesional, fotografía y enlaces para descarga de CV y al perfil de github; una sección de habilidades tecnicas y una sección de proyectos destacados. Por ultimo inclye los datos de contacto.

El sitio fué desarrollado en HTML con esilos en CSS, aplicando Flexbox, grid y reglas at para declaración de fuentes. El diseño es responsivo para mejor visualización en diferentes resoluciones.
